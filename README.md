# 🏥 Hospital Management System (HMS)

Welcome to the **Hospital Management System** repository. This system is designed to streamline healthcare operations, patient administration, doctor scheduling, and billing workflows efficiently.

---

## 🚀 Quick Setup & Installation Guide

The complete source code and detailed configuration documentation are packed inside **`Hospital Management.zip`**.

### 1. Download & Extract
1. Download the file **`Hospital Management.zip`** from this repository (or clone/download the whole repository).
2. Right-click on the zip file and extract it to your preferred folder:
   * **Windows:** Right-click ➔ *Extract All...*
   * **Linux/macOS:** Run `unzip "Hospital Management.zip"`

---

### 2. Refer to the Detailed Setup Guide (PDF)
Inside the extracted folder, open the included guide:
📄 **`Setup Guide.pdf`** 

This document provides step-by-step instructions for:
* Required runtime dependencies (Server, Database, Runtime Environment)
* Database configuration and schema import
* Port configuration and environment variables
* Launching the application and default admin credentials

---

### 3. Quick Start (General Steps)

1. **Database Setup:**
   * Start your database server (e.g., MySQL / PostgreSQL / MongoDB).
   * Create the project database and import the provided `.sql` or schema dump file.

2. **Configuration:**
   * Open the config or `.env` file inside the extracted folder.
   * Update your database username, password, and port settings as mentioned in the PDF.

3. **Start the Application:**
   * Run the project launch command as specified in the PDF guide.
   * Access the portal through your browser at:
     ```text
     http://localhost:YOUR_PORT
     ```

---

## 🛠️ Features Included

- **Role-based Authentication:** Admin, Doctor, Receptionist, and Patient modules.
- **Patient Management:** Records, registration, OPD/IPD history.
- **Doctor & Appointments:** OPD schedule management, patient booking, and token system.
- **Billing & Invoicing:** Automated fee and treatment billing reports.
